# Cognitive Walkthrough of Google Translate

In Lecture 13, we learned that doing a cognitive walkthrough of a product is a good way of evaluating its design prior to having actual users test it out. To apply this concept, I will go through a cognitive walkthrough of the **Google Translate** app!

<div align="center">
  <img src="/../assets/images/translate_logo.png" alt="translate_logo">
</div>
The full cognitive walkthrough is found below. I brainstormed a set of user tasks, broke down each task into a sequence of actions, and answered the four questions and provided a temporary solution where appropriate. I chose two tasks that I commonly use the app for.

As a reminder, the four evaluative questions from lecture are:

_How easily can a user..._

1. _know they need to do something?_
2. _notice the correct action is available, and associate it with what they're trying to do?_
3. _based on what occurs after the action is taken, know that it was the right thing to have done?_
4. _understand how they've made progress towards their larger goal?_

Overall, I think this is well-built app based on the success of the cognitive walkthrough.

## Translate written text from one language to another

<div align="center" style="margin-bottom: 20px; margin-top: 20px">
  <img src="/../assets/images/google_translate.png" alt="google_translate">
</div>

**(a) Select the original and translated languages**

1. Yes? This could be intuitive for most users but perhaps instructing the user to select the languages would be useful.
2. Yes. Sample languages are displayed at the top of each text box.
3. Yes. The selected languages are colored blue and underlined.
4. Yes. A user can see the progress after a language is highlighted.

**(b) Paste the original text into the field**

1. Yes? It could be intuitive which box to type the original text into since users might read left to right, but extra instructions could help.
2. Yes. The blank text box implies needing to type something into it.
3. Yes. The user sees the translated text to the right when typing.
4. Yes. The user immediately sees the translated text appear as they type without having to click other buttons.

**(c) Click the copy translation icon**

1. Yes. The user knows that they need to copy going into this.
2. No. The user might copy the translated text by highlighting it manually and copying it using keyboard shortcuts. Perhaps highlight the copy icon after writing the text.
3. Yes. There is a "translation copied" message that appears after clicking the copy icon.
4. Yes.

## Record dialogue and listen to it in another language

<div align="center" style="margin-bottom: 20px; margin-top: 20px">
  <img src="/../assets/images/voice_translation.png" alt="voice_translation">
</div>

**(a) Start the recording**

1. Yes. The user knows this going into this.
2. Yes. There is a record button at the bottom left of the text box.
3. Yes. The recording button becomes blue when clicked.
4. Yes.

**(b) Speak the dialogue out loud**

1. Yes.
2. Yes. There is a "Speak Now" message that appears after clicking the record button, indicating that the app is listening.
3. Yes. As in the previous task, the user can see the live translation on the left text box.
4. Yes. The user sees the written translation in the left text box, so they know the app has the translation.

**(c) End the recording**

1. Yes? I have personally not ended the recording and I just proceed. Perhaps automatically ending the recording after not speaking for several seconds is useful.
2. Yes. The user can click the recording button again.
3. Yes. The recording button reverts to its original color.
4. Yes.

**(d) Click the Listen button in the translation box**

1. Yes? Hopefully the user does not assume that this feature does not exist. Perhaps highlight this during some sort of initial walkthrough.
2. Yes. There are a limited number of icons to choose from and the icons are fairly universally understandable.
3. Yes. The user can hear the playback.
4. Yes.
